# Security Policy

## Supported Versions
Only the latest major release receives security updates.  
See [Releases](https://github.com/mesotron-dev/taph/releases) for current versions.

## Reporting a Vulnerability
Please **do not report security vulnerabilities through public GitHub issues**.

Instead, send details privately to security@mesotron.dev.

You will receive a response within 72 hours. We follow responsible disclosure practices and will credit reporters in release notes unless you prefer anonymity.

Thank you for helping keep the project secure!
